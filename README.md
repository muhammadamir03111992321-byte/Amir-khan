# Fazal e Amin & Murad Technical Services

Website for Fazalamin Technical Services Company.

## Files
- `index.html` - the page
- `style.css` - styling
- `images/` - photos
- `video/` - work video

## Put it online with GitHub Pages
1. Create a new repository on github.com (for example `fazal-murad-services`), set to Public.
2. Click **Add file > Upload files**, drag in everything from this folder (keep `images` as a folder), then **Commit changes**.
3. Go to **Settings > Pages**. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Editing
Change phone, email or text directly in `index.html`. Add photos to `images/` and copy one of the `<figure>` blocks in the Recent work section.
